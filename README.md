# Lucid — Digital Marketing Landing Page

A client-ready concept website for **Lucid**, a Bengaluru digital marketing partner focused on short-form content, precision Meta advertising, and lead generation.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Brand palette
- `#2f4156` — Ink
- `#567c8d` — Slate
- `#f5efeb` — Paper
- `#c8d9e6` — Mist

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Notes
The email/social links are placeholders for the client handoff. Replace `hello@lucid.studio` and the `#` social links with the client's real details.
